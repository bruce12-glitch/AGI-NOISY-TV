# Theory-to-test map

This document distinguishes implementation checks from empirical hypotheses.

## Theorem 1: bounded escape under persistent deficit

The no-decay recurrence reaches `B_max` in at most `ceil(B_max / tau)` steps when utility is zero and `tau` is constant. The executable recurrence test is `tests/test_theorem1_escape_time.py`. The corridor diagnostic is generated by `experiments/run_escape_time.py` or the main suite and reported in `figures/fig_escape_time.png`.

The actual AED configuration uses a leaky accumulator and adaptive threshold. Therefore `B_max / tau` is a reference calculation, not a universal equality or an unconditional theorem about the environment.

## Utility discrimination

`tests/test_learning_progress.py` checks that falling prediction error has positive signed progress. `tests/test_empowerment.py` checks that an action-independent observation stream has low tabular mutual information while an action-controlled stream has high information. Together these tests operationalize the intended distinction between noisy and learnable regions.

## Mode-shift prediction

`tests/test_boredom_accumulator.py` and `tests/test_mode_shift.py` check the state machine. `run_boredom_dynamics.py` logs `B_t`, `tau_t`, utility, entropy, and `mode_shift`; the plotting script marks threshold crossings. A paper-level claim that entropy spikes at crossings still requires a preregistered windowed statistical analysis across seeds rather than visual inspection of one trajectory.

## Long-run extrinsic performance

`figures/fig_regret_curves.png` is based on cumulative observed external reward. `results/summary/statistical_tests.csv` compares independent seed-level reward and escape metrics. This is evidence for the configured task, not a general regret theorem.

## Contraction sanity check

`tests/test_theorem2_contraction.py` verifies the standard discounted Bellman contraction in a toy finite-state operator. It does not prove contraction for an arbitrary adaptive or history-dependent AED process; the assumptions of any formal theorem must be stated separately in the paper.

## Limitations

The suite is tabular, continuing, and intentionally hand-designed. It does not establish open-ended learning, AGI, human-like boredom, or performance outside the stated stochastic corridor. `aed/models/rssm_world_model.py` and the MiniGrid wrapper are explicit extension points and are not included in the default evidence package.
